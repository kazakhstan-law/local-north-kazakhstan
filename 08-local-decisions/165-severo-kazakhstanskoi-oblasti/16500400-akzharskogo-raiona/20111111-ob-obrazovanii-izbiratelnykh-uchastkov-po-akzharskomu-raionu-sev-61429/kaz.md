# Солтүстік Қазақстан облысы Ақжар ауданы бойынша сайлау учаскелерін құру жөнінде

«Қазақстан Республикасындағы жергілікті басқару және өзін өзі басқару туралы» Қазақстан Республикасының 2001 жылғы 23 қаңтардағы № 148 Заңының 33-бабы 2-тармағына, «Қазақстан Республикасындағы сайлау туралы» Қазақстан Республикасының 1995 жылғы 28 қыркүйектегі № 2464 Конституциялық Заңының 23-бабы 1, 2-тармақтарына сәйкес аудан әкімі ШЕШТІ:
