# Солтүстік Қазақстан облысы Есіл ауданы Ильинка ауылдық округінің 2026-2028 жылдарға арналған бюджетін бекіту туралы

> *Ескерту. 01.01.2026 бастап қолданысқа енгізіледі – осы шешімнің 6-тармағымен.*

Қазақстан Республикасы Бюджет кодексінің 7-бабы 1-тармағының 4) тармақшасына, 85-бабының 3-тармағына, 89-бапқа, «Қазақстан Республикасындағы жергілікті мемлекеттік басқару және өзін-өзі басқару туралы» Қазақстан Республикасы Заңының 6-бабының 2-7-тармағына сәйкес Солтүстік Қазақстан облысы Есіл ауданының мәслихаты ШЕШІМ ҚАБЫЛДАДЫ:

1. Солтүстік Қазақстан облысы Есіл ауданының Ильинка ауылдық округінің 2026-2028 жылдарға арналған бюджеті сәйкесінше 1, 2, 3 -қосымшаларға сәйкес, соның ішінде 2026 жылға келесі көлемдерде бекітілсін:

   1) кірістер - 32 503 мың теңге:

      салықтық түсімдер - 12 105 мың теңге;

      салықтық емес түсімдер - 0 мың теңге;

      негізгі капиталды сатудан түсетін түсімдер - 0 мың теңге;

      арнаулы түсімдер -0 мың теңге;

      трансферттер түсімі - 20 398 мың теңге;

   2) шығындар - 32 503 мың теңге;

   3) таза бюджеттік кредиттеу - 0 мың теңге:

      бюджеттік кредиттер - 0 мың теңге;

      бюджеттік кредиттерді өтеу - 0 мың теңге;

   4) қаржылық активтермен жасалатын операциялар бойынша сальдо - 0 мың теңге:

      қаржылық активтерді сатып алу - 0 мың теңге;

      мемлекеттің қаржылық активтерін сатудан түсетін түсімдер - 0 мың теңге;

   5) бюджет тапшылығы (профициті) - 0 мың теңге;

   6) бюджеттің мұнайға қатысты емес тапшылығы (профициті) - 0 мың теңге;

   7) бюджет тапшылығын қаржыландыру (профицитін пайдалану) - 0 мың теңге:

      қарыздар түсімі - 0 мың теңге;

      қарыздарды өтеу - 0 мың теңге;

      бюджет қаражатының пайдаланылатын қалдықтары - 0 мың теңге.

2. Ильинка ауылдық округінің 2026 жылға арналған бюджетінің кірістері Қазақстан Республикасының Бюджет кодексінің 27-бабына сәйкес қалыптастырылатыны белгіленсін.

3. 2026 жылға аудандық бюджеттен Ильинка ауылдық округінің бюджетіне 17 152 мың теңге сомада трансферттер (субвенциялар) көлемдері қарастырылсын.

4. Ильинка ауылдық округінің 2026 жылға арналған бюджетінде облыстық бюджеттен нысаналы трансферттер түсімі қарастырылсын, соның ішінде:

   жергілікті атқарушы органдар бойынша мемлекеттік қызметшілердің төменгі санаттарына лауазымдық жалақыларын арттыруға.

   Аталған трансферттерді облыстық бюджеттен бөлу «Солтүстік Қазақстан облысы Есіл ауданы Ильинка ауылдық округінің 2026-2028 жылдарға арналған бюджетін бекіту туралы» Есіл ауданы мәслихатының шешімін жүзеге асыру туралы» Солтүстік Қазақстан облысы Есіл ауданы Ильинка ауылдық округі әкімінің шешімімен анықталады.

5. Солтүстік Қазақстан облысы Есіл ауданы Ильинка ауылдық округінің 2026 жылға арналған бюджетінде аудандық бюджеттен берілетін нысаналы ағымдағы трансферттердің көлемдері қарастырылсын, соның ішінде:

   елді мекендерді абаттандыру мен көгалдандыруға.

   Аталған трансферттерді аудандық бюджеттен бөлу «Солтүстік Қазақстан облысы Есіл ауданы Ильинка ауылдық округінің 2026-2028 жылдарға арналған бюджетін бекіту туралы» Есіл ауданы мәслихатының шешімін жүзеге асыру туралы» Солтүстік Қазақстан облысы Есіл ауданы Ильинка ауылдық округі әкімінің шешімімен анықталады.

6. Осы шешім 2026 жылғы 1 қаңтардан бастап қолданысқа енгізіледі.

**Солтүстік Қазақстан облысы Есіл ауданы мәслихатының төрағасы**

> *2025 жылғы 24 желтоқсандағы*  
> *№ 37/548 шешіміне*  
> *1-қосымша*
