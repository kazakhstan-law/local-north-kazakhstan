# Қауымдық сервитутты белгілеу туралы

Қазақстан Республикасы Жер Кодексінің 19-бабы 1-1) тармақшасына, 69-бабы 4-тармағына сәйкес Солтүстік Қазақстан облысы Мамлют ауданы Становое ауылдық округінің әкімі ШЕШІМ қабылдайды;

<a id="p1"></a>

1. «Солтүстік Қазақстан облысы Мамлют ауданы әкімдігінің сәулет, құрылыс, тұрғын үй коммуналдық шаруашылығы, жолаушылар көлігі және автомобиль жолдары бөлімі» коммуналдық мемлекеттік мекемесінесумен жабдықтаудың таратушы желілері үшін Солтүстік Қазақстан облысы, Становое ауылдық округі, Афонькино ауылының аумағында орналасқан жалпы ауданы 0,1990 гектар жер учаскесіне су құбыры ғимаратын салу үшін (қоғамдық сервитут) құқығы белгіленсін.

<a id="p2"></a>

2. «Солтүстік Қазақстан облысы Мамлют ауданы Становое ауылдық округі әкімінің аппараты» коммуналдық мемлекеттік мекемесі Қазақстан Республикасының заңнамасында белгіленген тәртіппен осы шешімнен туындайтын шараларды қабылдасын.

<a id="p3"></a>

3. Осы шешімнің орындалуын бақылауды өзіме қалдырамын.

<a id="p4"></a>

4. Осы шешім алғашқы ресми жарияланған күнінен кейін қолданысқа енгізіледі.

**Ауылдық округінің әкімі**

**Т. Ілиясов**
