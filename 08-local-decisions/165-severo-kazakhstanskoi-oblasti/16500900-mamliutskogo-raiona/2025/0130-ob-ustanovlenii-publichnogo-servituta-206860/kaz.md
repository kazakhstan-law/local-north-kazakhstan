# Қауымдық сервитутты белгілеу туралы

Қазақстан Республикасы Жер кодексінің 19-бабы 1-1) тармақшасына сәйкес Солтүстік Қазақстан облысы Мамлют ауданы Леденев ауылдық округінің әкімі ШЕШІМ ҚАБЫЛДАДЫ:

<a id="p1"></a>

1. «Солтүстік-Қазақстан Электржелістік Тарату Компаниясы» акционерлік қоғамына электр беру желілерін (ВЛ-10кВ Фидер №6 «Боголюбово-Зерноток» электр беру желілері) пайдалану үшін Солтүстік Қазақстан облысы Мамлют ауданы Леденево ауылының аумағында орналасқан жалпы алаңы 0,2650 гектар жер учаскесіне қауымдық сервитут 49 жыл мерзімге белгіленсін.

<a id="p2"></a>

2. «Солтүстік Қазақстан облысы Мамлют ауданы Леденев ауылдық округі әкімінің аппараты» коммуналдық мемлекеттік мекемесі осы шешімнен туындайтын шараларды қабылдасын.

<a id="p3"></a>

3. Осы шешімнің орындалуын бақылауды өзіме қалдырамын.

<a id="p4"></a>

4. Осы шешім алғашқы ресми жарияланған күнінен кейін күнтізбелік он күн өткен соң қолданысқа енгізіледі.

**Леденев ауылдық округінің әкімі**

**А. Исманов**
