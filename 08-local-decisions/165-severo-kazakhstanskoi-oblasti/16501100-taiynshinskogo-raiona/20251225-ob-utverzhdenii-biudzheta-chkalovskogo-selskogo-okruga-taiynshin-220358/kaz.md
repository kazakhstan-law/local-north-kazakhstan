# Солтүстік Қазақстан облысы Тайынша ауданы Чкалов ауылдық округінің 2026-2028 жылдарға арналған бюджетін бекіту туралы

> *Ескерту. 01.01.2026 бастап қолданысқа енгізіледі – осы шешімнің 5-тармағымен.*

Қазақстан Республикасы Бюджет кодексінің 91-бабының 3-тармағына, «Қазақстан Республикасындағы жергілікті мемлекеттік басқару және өзін-өзі басқару туралы» Қазақстан Республикасы Заңының 6-бабының 2-7-тармағына сәйкес Солтүстік Қазақстан облысы Тайынша ауданының мәслихаты ШЕШІМ ҚАБЫЛДАДЫ:

1. Солтүстік Қазақстан облысы Тайынша ауданының Чкалов ауылдық округінің 2026-2028 жылдарға арналған бюджеті тиісінше осы шешімнің 1, 2 және 3 - қосымшаларына сәйкес, оның ішінде 2026 жылға мынадай көлемдерде бекітілсін:

   1) кірістер – 102695 мың теңге:

      салықтық түсімдер – 40172 мың теңге;

      салықтық емес түсімдер – 0 мың теңге;

      негізгі капиталды сатудан түсетін түсімдер – 1776 мың теңге;

      трансферттер түсімі – 60747 мың теңге;

   2) шығындар – 102695 мың теңге;

   3) таза бюджеттік кредиттеу – 0 мың теңге:

      бюджеттік кредиттер – 0 мың теңге;

      бюджеттік кредиттерді өтеу – 0 мың теңге;

   4) қаржы активтері мен операциялар бойынша сальдо – 0 мың теңге:

      қаржы активтерін сатып алу – 0 мың теңге;

      мемлекеттің қаржы активтерін сатудан түсетін түсімдер – 0 мың теңге;

   5) бюджет тапшылығы (профициті) – 0 мың теңге;

   6) бюджеттің мұнайға қатысты емес тапшылығы (профициті) – 0 мың теңге;

   7) бюджет тапшылығын қаржыландыру (профицитін пайдалану) – 0 мың теңге:

      қарыздар түсімі – 0 мың теңге;

      қарыздарды өтеу – 0 мың теңге;

      бюджет қаражатының пайдаланылатын қалдықтары – 0 мың теңге.

      бюджет қаражатының пайдаланылатын қалдықтары – 0 мың теңге.

2. Солтүстік Қазақстан облысы Тайынша ауданы Чкалов ауылдық округінің кірістері Қазақстан Республикасының Бюджет кодексіне сәйкес қалыптасатыны белгіленсін.

3. 2026 жылға арналған Чкалов ауылдық округінің бюджетінде облыстық бюджеттен ағымдағы нысаналы трансферттердің түсімі 5956 мың теңге сомасында ескерілсін

4. 2026 жылға арналған аудандық бюджеттен Чкалов ауылдық округінің бюджетіне берілетін бюджеттік субвенция 54791 мың теңге сомасында белгіленсін.

5. Осы шешім 2026 жылғы 1 қаңтардан бастап қолданысқа енгізіледі.

**Солтүстік Қазақстан облысы Тайынша ауданы мәслихатының төрағасы**
