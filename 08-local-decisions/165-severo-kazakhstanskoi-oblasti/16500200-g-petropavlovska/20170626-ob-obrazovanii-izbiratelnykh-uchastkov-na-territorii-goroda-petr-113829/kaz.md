# Петропавл қаласының аумағында сайлау учаскелерін құру туралы

«Қазақстан Республикасындағы сайлау туралы» Қазақстан Республикасының 1995 жылғы 28 қыркүйектегі Конституциялық заңы 23-бабына, «Құқықтық актілер туралы» Қазақстан Республикасының 2016 жылғы 6 сәуірдегі Заңының 27-бабына сәйкес Солтүстік Қазақстан облысы Петропавл қаласының әкімі ШЕШТІ:

1. Петропавл қаласының аумағында сайлау учаскелері құрылсын, 1-қосымшаға сәйкес.

2. Петропавл қаласы әкімінің кейбір шешімдерінің күші жойылды деп танылсын, 2-қосымшаға сәйкес.

3. Осы шешімнің орындалуын бақылау Петропавл қаласы әкімі аппаратының басшысына жүктелсін.

4. Осы шешім оны бірінші ресми жариялаған күнінен бастап қолданысқа енгізіледі.

## Части документа

Документ разбит на части: целиком он слишком велик, чтобы GitHub его показал.
Каждая часть — это отдельный файл рядом с этим, и вместе они составляют полный
текст редакции.

| Часть | Название |
|---|---|
| [`an000`](kaz/an000.md) | `!` Сайлау учаскелері |
| [`an001`](kaz/an001.md) | Петропавл қаласы әкімінің кейбір күші жойылған шешімдерінің тізбесі |

Части, помеченные `!`, всё равно превышают лимит. Таблицы разрезаны по строкам,
но разрез ставится только там, где через него не проходит ячейка с `rowspan` —
иначе она перестала бы относиться к своим строкам. Если такого места нет, или
одна строка сама по себе больше лимита, часть остаётся целой. Её видно в `Raw`
и в клоне репозитория.
